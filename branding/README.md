# Dockup brand assets

The mark is a **D with an up-arrow cut out** (D + up = Dockup) on a blue-to-indigo tile.

| File | Use |
|---|---|
| `dockup-mark.svg`, `dockup-mark-512.png`, `dockup-mark-192.png` | App icon, avatars, social profiles |
| `favicon-32.png`, `apple-touch-icon.png` | Browser and home-screen icons |
| `dockup-logo-dark.svg/.png` | Horizontal logo on dark backgrounds |
| `dockup-logo-light.svg/.png` | Horizontal logo on light backgrounds |
| `dockup-glyph.svg` | Single-colour glyph (uses `currentColor`) for print, stamps, monochrome UI |

- Colours: tile gradient `#3B82F6` → `#4338CA`; accent "up" `#3B82F6` (dark) / `#2563EB` (light); text `#E6EDF3` (dark) / `#111418` (light).
- Wordmark: Inter Bold, tracking −2.5%, lowercase `dockup` with **up** in the accent colour (outlined in the SVGs, no font needed).
- Give the mark clear space of at least ¼ of its height; don't recolour the glyph inside the tile or add effects.
